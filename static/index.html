How SignalScope works

Image → preprocessing & augmentation → CV detector → calibrated verdict → explainer → responsible UI.

How to read a verdict

Likely AI-generated
Means the pixel evidence is strong, not that the image is proven fake. Use it as a reason to verify the source.
Inconclusive
Is a real answer. On an unseen generator, a hedged call is more useful than a confident wrong one.
Missing metadata
Is not evidence. Platforms strip C2PA and EXIF routinely, so absence never counts against an image.

Core Task & Responsibility

Accept a single image and output real / AI-generated plus a confidence score. Evaluation requires ROC-AUC, macro-F1 and a confusion matrix on the organisers' held-out test set.
Use wording such as “likely AI-generated” and communicate uncertainty. Do not target identifiable people, political claims or real-world events.
